## What to verify when studying

- Distinguish the mathematical model from the particular optimized C++ approach.
- Verify base cases and problem-specific constraints.
- Follow local relative links within the repository, not a single Markdown file outside its directory.
- Mermaid diagrams use short explicit labels to avoid GitHub truncation.
