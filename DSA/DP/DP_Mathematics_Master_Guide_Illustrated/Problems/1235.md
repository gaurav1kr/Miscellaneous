## Detailed dry run — Weighted interval scheduling: skip or take job

### Start from the mathematical question

Sort jobs by finish time. Let F(i) be the best profit using the first i jobs; p(i) is the last job ending no later than the start of job i.

### Derive the recurrence

```math
F(i)=\max(F(i-1),\ profit_i+F(p(i)))
```

**Why the transition is correct:** If job i is selected, all overlapping jobs are excluded, so jump to the latest compatible prefix. Binary search finds p(i) efficiently.

### Concrete example

**Input:** `jobs = (1,3,50), (2,4,10), (3,5,40), (3,6,70)`

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution 
{
public:
    int jobScheduling(vector<int>& startTime, vector<int>& endTime, vector<int>& profit) 
	{
        const int n = startTime.size();
        vector<vector<int>> jobs(n);
        for (int i = 0; i < n; i++) 
		{
			jobs[i] = {endTime[i], startTime[i], profit[i]};
		}
        sort(jobs.begin(), jobs.end());

        map<int, int> dp = {{0, 0}};
        for (auto& job : jobs) 
		{
            int profit = prev(dp.upper_bound(job[1]))->second + job[2];
            
            if (profit > dp.rbegin()->second) 
			{
				dp[job[0]] = profit;
			}
        }
        return dp.rbegin()->second;
    }
};
```
