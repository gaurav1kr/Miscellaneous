## Worked mathematical walkthrough (illustrated)

**State:** Number of valid routes ending at cell r,c.

**Transition:** `P(r,c)=P(r-1,c)+P(r,c-1) for unblocked cells; otherwise 0`

**Why:** Every arrival comes from above or left. Since the last move is different, the two sets of paths do not overlap. Blocked cells contribute zero.

## Detailed dry run — Unique Paths II: blocked states contribute zero

### Start from the mathematical question

Let W(r,c) count legal paths to (r,c); an obstacle removes all paths through its cell.

### Derive the recurrence

```math
W(r,c)=\begin{cases}0 & obstacle(r,c)\\W(r-1,c)+W(r,c-1)& otherwise\end{cases}
```

**Why the transition is correct:** The same last-step counting recurrence works, except invalid states have zero ways. The in-place 1D update preserves the previous-row count until it is overwritten.

### Concrete example

**Input:** `grid = [[0,0,0],[0,1,0],[0,0,0]]`

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution 
{
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) 
    {
        int m = obstacleGrid.size();
        int n = obstacleGrid[0].size();
        
        // If the starting point or ending point is blocked, no paths are possible
        if (obstacleGrid[0][0] == 1 || obstacleGrid[m-1][n-1] == 1) 
        {
            return 0;
        }
        
        // DP array to store the number of ways to reach each cell in the current row
        vector<int> dp(n, 0);
        dp[0] = 1; // Start point
        
        for (int i = 0; i < m; ++i) 
        {
            for (int j = 0; j < n; ++j) 
            {
                if (obstacleGrid[i][j] == 1) 
                {
                    dp[j] = 0; // No path through an obstacle
                } 
                else if (j > 0) 
                {
                    dp[j] += dp[j - 1]; // Add paths from the left cell
                }
            }
        }
        
        return dp[n - 1];
    }
};
```
