## Detailed dry run — LCS: match-or-drop prefixes

### Start from the mathematical question

Let L(i,j) be the LCS length of the first i characters of A and first j characters of B.

### Derive the recurrence

```math
L(i,j)=\begin{cases}1+L(i-1,j-1)&A[i-1]=B[j-1]\\\max(L(i-1,j),L(i,j-1))&otherwise\end{cases}
```

**Why the transition is correct:** Matching final characters can be paired; otherwise at least one final character must be excluded. This creates a complete case split.

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<int> prev(n + 1, 0), curr(n + 1, 0);

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (text1[i - 1] == text2[j - 1]) {
                curr[j] = 1 + prev[j - 1];
            } else {
                curr[j] = max(prev[j], curr[j - 1]);
            }
        }
        prev = curr;
    }

    return prev[n];
}
};
```
