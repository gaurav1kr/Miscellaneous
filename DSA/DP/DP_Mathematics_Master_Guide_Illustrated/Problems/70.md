## Detailed dry run — Climbing stairs: count disjoint last moves

### Start from the mathematical question

Let W(n) be the number of ways to climb n stairs using moves of size 1 or 2. Set W(0)=1: there is one empty sequence of moves.

### Derive the recurrence

```math
W(n)=W(n-1)+W(n-2)
```

**Why the transition is correct:** Partition all valid paths by their final move. A path cannot end in both a 1-step and 2-step move, so summing does not double-count.

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution 
{
public:
    int climbStairs(int n) 
    {
        if ( (n==1) || (n==0) )
        {
            return n ;
        }
        int a = 0 , b = 1 , c = 0 , i = 0 ;
        
        for(i=0;i<n;i++)
        {
            c = a + b ;
            a = b ;
            b = c ;
        }
        return c ;
    }
};
```

## Time and Space Complexity

- **Time:** `O(n)`
- **Auxiliary space:** `O(1)`

**Reasoning:** One iteration per step, retaining only the previous two values.
