## Worked mathematical walkthrough (illustrated)

**State:** L(i): best increasing subsequence ending exactly at i.

**Transition:** `L(i)=1+max(L(j) for j<i and a[j]<a[i]); empty maximum=0`

**Why:** Choose the previous element of the subsequence. The strict inequality makes the transition legal; taking the maximum finds the best predecessor.

## Detailed dry run — LIS: best subsequence ending at each index

### Start from the mathematical question

Let L(i) be the length of the longest strictly increasing subsequence whose final index is i.

### Derive the recurrence

```math
L(i)=1+\max_{j<i,\ a_j<a_i}L(j)
```

**Why the transition is correct:** Any increasing subsequence ending at i either has no predecessor (length 1) or extends one ending at a smaller previous value. Your submitted code may use an O(n log n) tails array, which is an optimized alternative invariant.

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
    int lengthOfLIS(std::vector<int>& nums) {
        std::vector<int> lis;
        for (int num : nums) {
            auto it = std::lower_bound(lis.begin(), lis.end(), num);
            if (it == lis.end()) lis.push_back(num);
            else *it = num;
        }
        return lis.size();
    }
};
```

## Time and Space Complexity

- **Time:** `O(n log n)`
- **Auxiliary space:** `O(n)`

**Reasoning:** For each value, binary search the tails array; the array can contain up to n values.
