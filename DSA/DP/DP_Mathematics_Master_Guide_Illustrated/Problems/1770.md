### Model / useful recurrence

`L(i)=1+\max_{j<i,\;a_j<a_i}L(j)`

**Why this helps:** When there is no predecessor, length is one. More advanced variants add dimensions such as last difference or number of chosen elements.

## Your original Accepted C++ submission (unaltered)

```cpp
#include <vector>

using namespace std;

class Solution {
public:
    int maximumScore(vector<int>& nums, vector<int>& multipliers) {
        int n = nums.size(), m = multipliers.size();
        vector<vector<int>> dp(m + 1, vector<int>(m + 1, 0));

        for (int i = m - 1; i >= 0; --i) {
            for (int l = i; l >= 0; --l) {
                int r = n - 1 - (i - l);
                dp[i][l] = max(
                    nums[l] * multipliers[i] + dp[i + 1][l + 1],
                    nums[r] * multipliers[i] + dp[i + 1][l]
                );
            }
        }
        return dp[0][0];
    }
};
```
