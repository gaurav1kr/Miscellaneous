## Understand the mathematics first

Each number is included or excluded.

### Model / useful recurrence

`P(i,s)=P(i-1,s) OR P(i-1,s-a_i)`

**Why this helps:** Boolean knapsack; target is half the total sum.

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int totalSum = accumulate(nums.begin(), nums.end(), 0);

        // If the total sum is odd, we cannot partition into two equal subsets
        if (totalSum % 2 != 0) {
            return false;
        }

        int target = totalSum / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true; // Base case: subset with sum 0 is always possible

        for (int num : nums) {
            for (int j = target; j >= num; --j) {
                dp[j] = dp[j] || dp[j - num];
            }
        }

        return dp[target];
    }
};
```
