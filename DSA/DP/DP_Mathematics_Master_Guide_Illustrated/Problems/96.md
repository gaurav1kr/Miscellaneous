## Detailed dry run — Catalan numbers: choose the BST root

### Start from the mathematical question

Let T(n) be the number of structurally different BSTs with n ordered keys. T(0)=1 (empty subtree).

### Derive the recurrence

```math
T(n)=\sum_{k=1}^{n}T(k-1)T(n-k)
```

**Why the transition is correct:** Choose the root; then choose independent left and right subtree shapes. Multiply independent choices, add across mutually exclusive roots.

## Your original Accepted C++ submission (unaltered)

```cpp
#include <vector>

class Solution {
public:
    int numTrees(int n) {
        std::vector<int> dp(n + 1, 0);
        dp[0] = 1; // Base case: Empty tree
        dp[1] = 1; // Base case: Tree with one node

        for (int i = 2; i <= n; ++i) { // Compute dp[i] for all 2 <= i <= n
            for (int j = 1; j <= i; ++j) { // Consider each node as root
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }

        return dp[n];
    }
};
```
