## Understand the mathematics first

Choose each possible root; left and right trees are independent.

### Model / useful recurrence

`C(n)=sum_{k=1..n} C(k-1)*C(n-k)`

**Why this helps:** Catalan recurrence; multiply independent choices, sum alternative roots.

## Your original Accepted C++ submission (unaltered)

```cpp
#include <vector>

class Solution {
public:
    int numTrees(int n) {
        std::vector<int> dp(n + 1, 0);
        dp[0] = 1; // Base case: Empty tree
        dp[1] = 1; // Base case: Tree with one node

        for (int i = 2; i <= n; ++i) { // Compute dp[i] for all 2 <= i <= n
            for (int j = 1; j <= i; ++j) { // Consider each node as root
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }

        return dp[n];
    }
};
```
