## Understand the mathematics first

Count arrangements of fixed right and down steps.

### Model / useful recurrence

`C(m+n-2,m-1)=(m+n-2)!/((m-1)!(n-1)!)`

**Why this helps:** Your submission uses combinatorics, not a DP table.

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
   int uniquePaths(int m, int n) {
        long long res = 1;
        int N = m + n - 2; // Total steps (right + down)
        int k = std::min(m - 1, n - 1); // Choose the smaller set (right or down)
        
        for (int i = 1; i <= k; i++) {
            res = res * (N - i + 1) / i; // Compute binomial coefficient (N choose k)
        }
        
        return res;
    }
};
```
