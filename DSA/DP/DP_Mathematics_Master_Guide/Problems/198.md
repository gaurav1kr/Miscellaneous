# 198. House Robber

**Difficulty:** Medium

## Understand the mathematics first

Let F(i) be best from first i houses.

### Model / useful recurrence

`F(i)=max(F(i-1),a_i+F(i-2))`

**Why this helps:** Take/skip. Adjacent houses cannot both be chosen.

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
    int rob(vector<int>& nums) 
    {
        int prev1 = 0;
        int prev2 = 0 ;
        for(int num:nums)
        {
            int temp = prev1 ;
            prev1 = max(prev2 + num , prev1) ;
            prev2 = temp ;
        }
        return prev1 ;
    }
};

//Reoccurrence
// dp[i] = max(dp[i-1], nums[i] + dp[i-2])
```
