## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
bool isSubsequence(string s, string t) {
    int i = 0, j = 0;
    while (i < s.size() && j < t.size()) {
        if (s[i] == t[j]) i++;
        j++;
    }
    return i == s.size();
}
};
```
