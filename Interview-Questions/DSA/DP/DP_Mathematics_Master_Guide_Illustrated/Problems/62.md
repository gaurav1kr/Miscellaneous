## Detailed dry run — Unique Paths: count by last direction

### Start from the mathematical question

Let W(r,c) count paths from (0,0) to cell (r,c), moving only down/right.

### Derive the recurrence

```math
W(r,c)=W(r-1,c)+W(r,c-1)
```

**Why the transition is correct:** A path reaches a non-boundary cell from above or left, and these last steps partition all paths. Your submitted solution instead uses the equivalent binomial coefficient C(m+n−2,m−1).

## Your original Accepted C++ submission (unaltered)

```cpp
class Solution {
public:
   int uniquePaths(int m, int n) {
        long long res = 1;
        int N = m + n - 2; // Total steps (right + down)
        int k = std::min(m - 1, n - 1); // Choose the smaller set (right or down)
        
        for (int i = 1; i <= k; i++) {
            res = res * (N - i + 1) / i; // Compute binomial coefficient (N choose k)
        }
        
        return res;
    }
};
```
